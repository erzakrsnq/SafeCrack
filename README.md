# Safe Crack - Numbers

Innovation Lab WH

Safe Crack - Numbers ist ein Unity-Spiel, in dem ein digitaler Safe durch das Loesen von Zahlenreihen geoeffnet wird. Der Spieler muss die mathematische Regel hinter einer Folge erkennen und die naechste Zahl eingeben. Die Anzahl der Versuche ist begrenzt.

Um das Level zu bestehen, muessen vier unterschiedliche Zahlenreihen korrekt geloest werden. Das Spiel beruecksichtigt auch Fehlerfaelle wie leere, ungueltige oder nicht numerische Eingaben sowie zu viele falsche Versuche.

Kunde: Fabian Wagner
